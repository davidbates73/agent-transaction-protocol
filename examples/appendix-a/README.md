# Appendix A worked example — real, signed

This is the seven-node MCP tool discovery and invocation chain from draft-bates-atp Appendix A. It uses real payload hashes, real nodeIds, and real Ed25519 signatures from three issuers.

| File | Contents |
|---|---|
| `bundle.json` | §16.12 Pattern X bundle of the 7 signed nodes |
| `keys.json` | Public keys, keyed by `issuerId\|keyId` |
| `payloads.json` | The off-chain payloads the `inputHash`/`outputHash` values cover |

Generated by `implementations/node/bin/demo.js --write`. Python rebuilds it byte-for-byte with `implementations/python/atp_cli.py interop`.

The signing seeds are `SHA-256("atp-demo-seed:<issuerId>:<keyId>")`. **Test keys only.**

These nodeIds can replace the `<nodeId of Node N>` and `sha256:ab12...` placeholders in Appendix A of -01.
